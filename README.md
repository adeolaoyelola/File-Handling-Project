Secret Agent Message File Handler

About the Project

This is a beginner Python project that allows a secret agent to manage messages stored in a text file.

The program uses file handling to create, write, append, read and delete a text file through a simple menu system.

Features

The program allows the user to:

Add a message to the file
Overwrite the existing file content
Clear the file content
Read all messages
Delete the file
Exit the program
Receive a success message after completing an option
What I Learned

Through this project, I practised:

Opening and closing files
Reading from a text file
Writing to a text file
Appending information to a file
Deleting files
Using if, elif and else
Using while loops
Taking user input
Creating a menu-driven program
Using error handling for situations such as a file not existing

Python
Text files (.txt)
